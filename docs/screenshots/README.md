# Скриншоты для просмотра агентом

Сюда кладут PNG/JPEG, которые нужно показать агенту (или приложить к задаче). CI не нужен:
агент читает файл прямо из рабочего дерева.

Правила:

- имя `<дата>-<тема>-<before|after>.png`, без пробелов и кириллицы: `2026-10-24-signin-before.png`;
- формат PNG (или JPEG), размер до ~2 МБ; кадр 390×844 из headless-теста весит 15–25 КБ;
- в сообщении коммита одной строкой — что смотреть: «метка Email наложена на текст»;
- коммиты, которые трогают только `docs/**`, не запускают CI (`paths-ignore` в `build.yml`).

Выгрузка кадров и `build.log` из CI-прогона идёт в `ci/reports/` (этот каталог в `.gitignore`):
`python3 tools/read_screenshots.py`. CI публикует их в ветку `ci/reports`. Полная памятка —
`docs/NOTES.md`, схема пайплайна — `docs/CI.md`, раздел 7.

Что уже пригодилось искать на кадрах HC: наложение текста (метка на значении), контент, который
не занимает высоту окна, обрезка по краям, пустые области. Ripple/focus-слой на мгновенном кадре
выглядит светлым пятном — это анимация, а не баг.
