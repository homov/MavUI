# Заметки миграции HC

Рабочие правила для кода `migrated/HC`. Их нужно соблюдать и людям, и агентам.

## Общее правило: сначала то, что есть

- Сначала используем то, что уже есть в MavUI (контролы, сервисы, механизмы). Новые решения не придумываем.
- Если подходящего нет или непонятно, какой вариант выбрать, спрашиваем пользователя. Не угадываем.
- Правила сервера (например, требования к паролю, длина кода) не выдумываем. Если их нет в `ref/`, спрашиваем.

## Проверка полей форм

- Все правила полей задаются через `MavFormValidator` (`Field(...)` и `MavFieldRuleBuilder`).
- Доступные правила: `Required`, `MinLength`, `MaxLength`, `Email`, `Numeric`, `Pattern`, `Matches`, `Must`.
- Ошибка поля выводится под полем (`ErrorText`, у `MavPinInput` через `HasError`), а не отдельным текстом.
- Вызов `Validate()` в начале действия формы. Если он вернул `false`, запрос на сервер не отправляется.
- Ручные проверки (`string.Contains("@")` и т. п.) и отдельные вспомогательные классы для проверки не пишем.

## Ошибки облачного API

- Ошибки вызовов API показываются в `MavBanner` (`Message`, `Show()`, `Dismiss()`).
- Баннер не используется для проверки полей.
- Текст ошибки формирует `ErrorText.From(Exception)` по виду ошибки (`CloudErrorKind`).

## Открытые вопросы

- Предупреждения `AVLN3001` по страницам аккаунта (XAML по пути времени выполнения). Решение не принято.
- Хранилище секретов на Windows и macOS не подключено (только libsecret на Linux).
